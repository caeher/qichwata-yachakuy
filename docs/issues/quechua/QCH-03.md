# Complementar Saludos y presencia con diálogos y gramática inicial

## Objetivo

Convertir `hola`, `presentarse` y `practica-01` del curso `saludos-y-presencia` en borradores de enseñanza lingüística, reemplazando las actividades actuales sobre el estado editorial.

## Documentos que se deben descargar

- [Libro de Alipio Pacheco Condori](https://www.pueblosoriginarios.gob.cl/sites/www.pueblosoriginarios.gob.cl/files/2022-02/Lengua%20y%20Cultura%20Quechuas_Alipio%20Pacheco.pdf).
- [Diccionario de Julio Calvo Pérez, volumen 1](https://apl.org.pe/wp-content/uploads/2022/07/DICCIONARIO-Quechua-espanol-VOL_1.pdf).

Registrar las descargas y condiciones de uso según QCH-01. Las páginas PDF indicadas se cuentan desde 1.

## Referencia curricular

Unidad 2 del libro, PDF 32–62: intercambios iniciales, interrogación, morfología y construcción de oraciones. Usar el diccionario como consulta léxica por entrada, no como secuencia de curso.

## Criterios de aceptación

- [x] Mapear cada objetivo y expresión actual a una referencia concreta; corregir o sustituir los candidatos sin respaldo.
- [x] Preparar una progresión con saludo, presentación, pregunta/respuesta y cierre; explicar el contexto de uso de cada expresión.
- [x] Introducir estructura aglutinante y preguntas con -chu/-ri donde corresponda a la variedad aprobada; distribuir la gramática en pasos breves.
- [x] Crear textos y diálogos originales, vocabulario, traducciones, ejemplos y actividades de comprensión y producción con retroalimentación.
- [x] Para cada actividad, definir respuesta esperada y alternativas revisadas; evitar ejercicios que solo pregunten si una frase es borrador.
- [x] Completar citas, autoría, variedad, objetivos y duración en el formato `CourseUnitContent`; conservar los identificadores de las unidades existentes. La atribución editorial humana y licencia de autoría quedan explícitamente pendientes, por lo que las unidades no pasan a publicación.
- [x] No añadir nuevas unidades: los objetivos caben en las tres existentes; orden y prerrequisitos quedan documentados.
- [x] Entregar para revisión humana; mantener `draft` hasta cumplir las condiciones actuales de publicación.
