# Preparar un glosario didáctico trazable a partir del diccionario

## Objetivo

Crear una selección léxica útil para las lecciones, preservando sentidos y contexto. El volumen suministrado es español→quechua; una búsqueda inversa en una selección no equivale a disponer del tomo quechua→español.

## Documentos que se deben descargar

- [Libro de Alipio Pacheco Condori](https://www.pueblosoriginarios.gob.cl/sites/www.pueblosoriginarios.gob.cl/files/2022-02/Lengua%20y%20Cultura%20Quechuas_Alipio%20Pacheco.pdf).
- [Diccionario de Julio Calvo Pérez, volumen 1](https://apl.org.pe/wp-content/uploads/2022/07/DICCIONARIO-Quechua-espanol-VOL_1.pdf).

Registrar las descargas y condiciones de uso según QCH-01. Las páginas PDF indicadas se cuentan desde 1.

## Análisis del índice y manejo

Revisar PDF 21–42 para estructura e interpretación de artículos, 43–51 para escritura, 52–55 para estrategias y 56–81 para abreviaturas. El cuerpo alfabético comienza en PDF 97 y termina en 2041.

El diseño de selección, estados y ficha se documenta en [`qch-05-glossary-v1.0.md`](../../quechua-sources/qch-05-glossary-v1.0.md). La matriz de candidatos ya separa respaldo curricular de cotejo lexicográfico y no introduce formas sin verificar. Falta registrar el análisis editorial específico de las páginas 21–81: el entorno actual no dispone de un renderizador PDF local y el acceso web al volumen completo excede el límite de lectura; no se ha sustituido esa revisión visual por extracción de texto.

## Criterios de aceptación

- [x] Definir selección por los objetivos de los tres cursos y registrar para cada candidato si tiene respaldo o sigue pendiente.
- [x] Modelar lema, dirección de consulta, acepción, categoría, marcas de uso, remisiones, variante, página impresa/PDF y estado de revisión.
- [x] Distinguir sinónimos, acepciones y expresiones; no aplanar cada artículo a una pareja de traducciones.
- [ ] Redactar explicaciones y ejemplos pedagógicos propios; registrar las condiciones autorizadas para cualquier extracto incorporado.
- [ ] Si se autoriza extracción, empezar por una muestra representativa y revisar columnas, cortes de palabra, apóstrofos, signos, subentradas y remisiones contra el PDF antes de ampliar el proceso. No hay autorización en QCH-01, por lo que la condición no se activa y no se ha extraído una muestra.
- [x] Definir cómo referenciar las fichas desde `vocabulary`, `phrases` y `sources` sin perder el vínculo a la acepción.
- [x] Distinguir explícitamente una consulta inversa sobre fichas revisadas de la fuente lexicográfica inversa aún pendiente en QCH-01.
- [x] Mantener las entradas sin resolver fuera del material publicado y del contexto del tutor.

El diseño no constituye un glosario validado: siguen pendientes la lectura visual de PDF 21–81, el cotejo de candidatos, explicaciones/ejemplos revisados y cualquier revisión lingüística. QCH-01 solo permite ahora consulta editorial privada, así que no hay extracción ni extracto que incorporar.

## Dependencias

QCH-01 y QCH-02. Aporta vocabulario a QCH-03, QCH-04 y QCH-06.
